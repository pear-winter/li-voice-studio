# ♪梨梨配音室

SillyTavern 配音插件，界面跟随酒馆主题。魔法棒菜单 → **♪梨梨配音室**。

安装地址：`https://github.com/pear-winter/li-voice-studio`

## 功能

- **配音**：MiniMax 直连，多角色音色、语种、播放和 MP3 下载。
- **存储**：录音逐条显示，日期、第一句话和音色作为标题，默认折叠。展开后查看全文、播放、下载或确认删除。支持内容、音色和日期搜索，保留音色筛选。
- **翻译**：配置独立副 API，选择目标语言，预览或编辑译文后点击「使用译文」，再手动生成配音。
- **选字**：同一楼层内的正文、状态栏、可选中文字和文本输入区均可配音，不限制 `<content>` 或 `.mes_text`。支持浏览器允许访问的同源 iframe；跨域或隔离 iframe 内的内容需复制到配音框。

无需酒馆助手、书摘或画室。书摘开启时仍可使用选字栏与划线栏中的配音按钮。

## 配置

MiniMax：选择密钥所属站点，填 API Key、模型和音色 Voice ID。Group ID 可留空，填写时须与 Key 属于同一账户。`1004: token not match group` 表示账户鉴权不匹配，与缺少 `https://` 无关。

副 API：使用与梨梨画室相同的 OpenAI 兼容聊天接口格式。填写地址、Key 和模型，可拉取模型或手动填写。支持 `https://服务商/v1` 或完整 `/chat/completions` 地址；无协议时补 `https://`，只有域名时补 `/v1`，其他路径保持原样。只发送当前配音框文本和翻译要求，不读取画室配置或聊天历史。

MiniMax 和副 API 均可保存多套命名接口（包含 Key、地址和模型），下拉切换；点击「保存并使用」后写入当前站点的 IndexedDB，刷新后自动恢复所选接口。新增接口会清空 Key，删除接口不会删除录音。配置与录音保存在当前浏览器，旧版本的数据继续沿用。清除网站数据会清除录音；录音可下载备份。接口需允许浏览器直接访问，插件不能绕过跨域限制。

## 自定义外观

配置 → 外观，默认「跟随酒馆」。选择「自定义 CSS」后编辑并保存，刷新后仍保留；「恢复默认」清空自定义样式并恢复主题配色。

`#lv-dialog` 对应配音室弹窗，`#lv-selection` 对应选字配音按钮。可使用内部类名（如 `.lv-head`、`.lv-tabs`、`.lv-page`）或 `button`、`textarea` 等选择器；样式限定在这两个组件内。支持 `@media`、`@supports` 和关键帧动画。

## 安卓版与同步

[下载安卓 APK 1.0.0](https://github.com/pear-winter/li-voice-studio/raw/refs/heads/main/downloads/li-voice-1.0.0.apk)

安卓应用 **♪梨梨配音室 1.0.0**，包名 `net.pearvoice.app`，支持 Android 8.0 及以上，需要较新的 Android System WebView。应用独立运行，无需酒馆或任何插件。配音与翻译使用联网 API，录音、歌曲、歌词、音色和接口保存在应用本地；已有音频可离线播放。卸载应用会删除本地数据。

**歌曲**：导入音频，展开条目后导入或更换 LRC。歌词随播放进度高亮，点击歌词跳转；支持 UTF-8 / GB18030、多个时间标签与 offset。可按歌名或歌词搜索、下载歌曲和歌词、确认删除。单首音频最大 50 MB。

**配置 → 导入与导出**：APK 与插件使用同一种 `.livoice.json` 文件，包含录音、歌曲及歌词、音色、已保存的 MiniMax / 副 API 接口。导入不会删除其他内容；重复 ID 默认保留本地版本，选择「使用导入版本」可更新已有音色、接口与歌词。外观与当前页面偏好仍使用本机设置。未导出 Key 时，导入不会清掉已有 Key。若要把 Key 一起迁移，导出前勾选「包含 API Key」；该文件包含明文 Key，请自行保管。单次同步音频总量最大 100 MB。

**1.8.0 插件**：新增歌曲与歌词存储、跨端导入导出；旧录音数据库自动升级并保留。酒馆助手脚本不随此版本更新。

### 构建 APK

安装 Android SDK Platform 35 / Build Tools 35.0.0、Java 17 与 Eclipse ECJ 3.38.0。设置 `ANDROID_SDK_ROOT`、`ECJ_JAR` 和 `VOICE_SIGNING_DIR` 后运行 `python3 android/build-apk.py`。签名目录包含 `release.p12` 与 `password.txt`，别名 `pear`；签名资料不得放入公开仓库。构建会从插件复制共享逻辑及样式到应用，输出 `android/build/li-voice-1.0.0.apk`。

验证：浏览器自动化覆盖数据库升级、跨端音频逐字节对比、合并去重、Key 选择性导出、非法文件拒绝、歌词定位及持久化；安卓包通过编译和 APK 签名校验。未使用真实 MiniMax 账户计费合成，尚未在实体安卓设备上验收。
