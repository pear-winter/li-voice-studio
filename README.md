# v1.11.0 更新

- 配音首页可以切换 MiniMax / 鱼声；在配置的鱼声接口中保存地址、模型与 Key，音色管理中为每个角色填写鱼声 Reference ID。两个接口的声线 ID 分开保存。
- 多角色台词独立一页。选择聊天文字后，在配音首页点「送入多角色配音」，拆分语段并分别选声线。支持原始 `<vo=角色>` 标记；未标记内容按句号和换行拆分。单次最多 40 段、每段 9999 字、成品 10 分钟。
- 每个小语段可生成试听，生成后反复试听不重复调用接口；正式批量合成会复用文字、声线、模型等设置都没改变的试听片段。已存储片段在组合器里也可试听。
- 存储分成大配音、单段、原片段。可改名、按日期预览删除、按起止日期打包 ZIP。结束日期包含当天，按当前设备的本地日期计算；被较新的大配音引用的片段会保留。
- 大配音点「后期配 BGM」可从原人声重新配乐并保存到同一成品。支持上传本地音乐和当前站点工作台已保存的本地音频；在线音乐先下载导入。重新打开后期配乐时，不选 BGM 会移除旧背景音乐。
- 文中台词播放继续使用 `__liVoiceStudio.speech`。MiniMax 的语气标记会转换为鱼声的提示标记；鱼声停顿长短是近似提示，不保证秒数精确。S1 会移除语气提示。
- 附带台词播放键 v1.1，切换配音接口时会停止旧播放并清理缓存；原「说话人标记」正则和世界书的 `<vo=说话人>` 格式继续使用。

配置、录音均保存在当前酒馆站点。此次未改动安卓 APK。

验证：Node 请求转换、日期边界、批量删除取消与引用保护测试通过；Python 独立解压 ZIP 并校验文件名、音频字节通过。运行环境未能下载浏览器，因此未完成浏览器回归。真实鱼声音频须使用用户自己的密钥试听确认。

# ♪梨梨配音室

SillyTavern 配音插件，界面跟随酒馆主题。魔法棒菜单 → **♪梨梨配音室**。

安装地址：`https://github.com/pear-winter/li-voice-studio`

## 功能

- **配音**：MiniMax 直连，多角色音色、语种、播放和 MP3 下载。
- **存储**：录音逐条显示，日期、第一句话和音色作为标题，默认折叠。展开后查看全文、播放、下载或确认删除。支持内容、音色和日期搜索，保留音色筛选。
- **翻译**：配置独立副 API，选择目标语言，预览或编辑译文后点击「使用译文」，再手动生成配音。
- **句尾播放**：在酒馆消息中选中字句并生成配音后，原句后显示 `▶`，可直接播放 / 暂停。同一句多次生成显示 `⋯`，选择第几版、查看音色和生成时间；默认播放最新版本，手动选择后记住偏好。
- **选字**：同一楼层内的正文、状态栏、可选中文字和文本输入区均可配音，不限制 `<content>` 或 `.mes_text`。支持浏览器允许访问的同源 iframe；跨域或隔离 iframe 内的内容需复制到配音框。

无需酒馆助手、书摘或画室。书摘开启时仍可使用选字栏与划线栏中的配音按钮。

## 配置

MiniMax：选择密钥所属站点，填 API Key、模型和音色 Voice ID。Group ID 可留空，填写时须与 Key 属于同一账户。`1004: token not match group` 表示账户鉴权不匹配，与缺少 `https://` 无关。

副 API：使用与梨梨画室相同的 OpenAI 兼容聊天接口格式。填写地址、Key 和模型，可拉取模型或手动填写。支持 `https://服务商/v1` 或完整 `/chat/completions` 地址；无协议时补 `https://`，只有域名时补 `/v1`，其他路径保持原样。只发送当前配音框文本和翻译要求，不读取画室配置或聊天历史。

MiniMax 和副 API 均可保存多套命名接口（包含 Key、地址和模型），下拉切换；点击「保存并使用」后写入当前站点的 IndexedDB，刷新后自动恢复所选接口。新增接口会清空 Key，删除接口不会删除录音。配置与录音保存在当前浏览器，旧版本的数据继续沿用。清除网站数据会清除录音；录音可下载备份。接口需允许浏览器直接访问，插件不能绕过跨域限制。

## 自定义外观

配置 → 外观，默认「跟随酒馆」。选择「自定义 CSS」后编辑并保存，刷新后仍保留；「恢复默认」清空自定义样式并恢复主题配色。

`#lv-dialog` 对应配音室弹窗，`#lv-selection` 对应选字配音按钮。可使用内部类名（如 `.lv-head`、`.lv-tabs`、`.lv-page`）或 `button`、`textarea` 等选择器；样式限定在这两个组件内。支持 `@media`、`@supports` 和关键帧动画。

## 1.10.2 播放器提前准备

可见句子的音频提前载入独立播放器，点击直接复用已准备好的播放器，不再点击后重设音源。最多预备 3 条、16 MB，切换聊天或卸载时释放；大音频仍按需加载。

## 1.10.1 播放响应修复

单条播放按 ID 读取音频和信息，不再遍历全部录音。少量可见配音提前读取到限量缓存；进度更新不会反复扫描聊天或 iframe。

## 1.10.0 新功能

- 句尾播放器跟随酒馆主题，带进度拖动、律动音波、下载和收藏。同一句的多次配音通过 `⋯` 切换。
- 新版梨梨工作台可直接管理已启用的配音室。收藏复制到音乐栏的「我的语音」，配音插件关闭后仍能播放；工作台未启用时先保存在配音室，之后再同步。
- 「多角色台词」每行选择音色、填写台词、调整顺序，一次生成并拼接完整对话。中途失败保留已完成片段；继续时复用没有修改的片段。
- 「存储」勾选录音 → 合成选中录音，可调整顺序、片段间隔、上传 BGM 和调节音量。合成后原片段收起，展开成品点「拆开大配音」恢复。拼接在本地完成，不调用配音 API；导出为 WAV。
- 合成上限：40 段、10 分钟、输入总量 100 MB；BGM 最大 50 MB。背景音乐循环铺满并淡入淡出。
- 插件移除歌曲与 LRC 功能，旧歌曲数据不清除；导入 App 同步文件时跳过歌曲。Android 应用保留歌曲功能，源码与样式已分开，插件更新不会改变 App。

录音和合成原片段一起随同步文件导出。旧录音没有原句位置时可在存储页播放，不自动绑定聊天句子。句尾按钮只装饰页面，不写入消息或发给模型；聊天原文改变后隐藏失效按钮。跨域 iframe 不能直接插入按钮。

## 1.10.3 小剧场配音接口

正式保留 `window.__liVoiceStudio.speech`（version: 1），用于监控终端、野火视窗等小剧场联动。扩展版与酒馆助手脚本版提供同一接口：

- `voices()`：音色列表；`ready()`：是否已配置；`model()`：当前模型。
- `find(text)`：按完整台词查找已保存录音。
- `speak(text, profileId)`：按音色生成并保存录音，返回录音信息。
- `url(id)`：获取录音的 Blob URL；调用方在播放结束或移除时负责 `URL.revokeObjectURL()`。
- `openConfig()`：打开配置页。

接口签名与用户提供的 v1.10.2 小剧场联动版一致，设置、音色、接口配置和录音沿用原存储。更新不清除本地数据。

酒馆助手版：导入 `helper/酒馆助手脚本-梨梨配音室-v1.10.3.json` 到全局脚本库，替换旧配音室脚本并启用。魔法棒 → ♪梨梨配音室。已有扩展运行时不会重复启动。

打包：`python3 helper/build-helper.py`，直接从正式版代码和样式生成，不需要另行添加联动补丁。

## 1.10.4 旧扩展与小剧场联动版共存修复

旧的 1.10.2 扩展不提供 `speech`。此前它已运行时，联动脚本会跳过启动，导致台词播放键提示没有检测到配音室。酒馆助手版现在检查完整接口：兼容的扩展继续复用；没有接口的旧扩展由脚本版接管，仍使用相同本地设置与录音。关闭脚本清理所属公开对象，避免残留失效实例。台词播放键和说话人正则无需修改。

模拟接口验证：先加载原版 1.10.2 扩展，再启用新版助手脚本和用户提供的台词播放键，完成选音色、生成、播放、历史复用，以及配置保留。
