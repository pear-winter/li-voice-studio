# ♪梨梨配音室

可直接安装到 SillyTavern 的 MiniMax 配音插件。入口位于左下角魔法棒菜单，配色和字体跟随酒馆主题。

## 安装

在酒馆「扩展 → 安装扩展」中粘贴：

```text
https://github.com/pear-winter/li-voice
```

安装后刷新酒馆，点击魔法棒中的 **♪梨梨配音室**。这是酒馆前端扩展，无需导入酒馆助手 JSON，也不需要额外安装服务器文件。

**如果之前使用脚本版，请先在酒馆助手中关闭旧脚本。** 在相同浏览器、相同酒馆站点安装，本插件沿用脚本版的音色配置和录音数据库，不清空已有录音。安装与更新不会自动生成配音。

## 三页功能

- **配音：** 输入句子，选择音色和语种，生成、播放、停止或下载 MP3。可配置多个角色音色。
- **存储：** 成功配音自动保存到本地，按音色筛选，重听、下载或确认删除。刷新后保留。
- **配置：** MiniMax 官方地址、API Key、模型、可选 Group ID、音色管理和连接诊断。

支持书摘选字栏和已有划线栏的「配音」按钮。未开启书摘时，选中同一条聊天正文内的文字，也能使用独立配音入口。

## 连接 MiniMax

1. 打开配置，选择密钥所属站点：中国站 `https://api.minimaxi.com` / `https://api.minimax.cn`，或国际站 `https://api.minimax.io`。
2. 填入该账户的 API Key。仅使用官方 HTTPS 直连，没有连接方式选项。密钥仅暂存在当前运行中，刷新后需要重填。
3. Group ID 不确定时留空；填写时必须与 API Key 属于同一账户。点击「检查连接」查询音色并验证鉴权，不提交配音。
4. 在音色管理中填写名称和 Voice ID 并保存。然后到配音页输入文本，选择音色、语种，再生成。

语种用于发音提示，不翻译原文。模型、音色及合成权限以实际账户为准。每次最多 9999 个字符，建议长文分段。付费合成不会自动重试；停止本地等待后，服务端可能仍完成请求并计费。

### `1004: token not match group`

这是 API Key 与 Group 不匹配的提示，不是地址缺少 `https://`。可以先清空 Group ID 再检查连接；仍报错时，核对账户站点并重新复制该账户的密钥。不要公开发送 API Key。

若浏览器报网络或 CORS 错误，需要检查本机网络及上游跨域策略；插件不能绕过浏览器限制。

## 数据保存

音色设置保存在当前站点的 localStorage，录音二进制保存在 IndexedDB。不会上传历史录音，不会发送完整聊天记录或角色卡，只在主动生成时向 MiniMax 发送当前文本与参数。

录音不跨设备同步；清除网站数据会清除录音，重要内容请下载备份。删除音色配置不会删除历史录音。存储空间不足时会提示，并保留本次音频供下载。

书摘联动支持主文档中的 `#be-float-bar`、`#be-hl-bar .be-hl-row1`、`.be-highlight[data-be-id]` 及 `.mes_text`。独立 iframe 和跨消息选区请复制到面板。

## 更新与验证

通过酒馆扩展管理更新本插件，之后刷新页面。

1.4.0 为原脚本版 1.3 的酒馆扩展版本。已用 Chromium 验证插件文件加载、菜单和名称、原配置沿用、模拟接口合成、录音刷新保存、下载与删除。未使用真实账户完成 MiniMax 合成测试；实际鉴权以账户结果为准。
